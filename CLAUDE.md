# Working on this repo

- **Keep the Guide tab up to date.** Every change that adds or changes a user-visible feature must also update `src/pages/Guide.tsx` in the same commit: plain everyday words, and a live example built from the app's own components (made-up data, no working buttons).
- Push directly to `main` (the owner deploys from it via Vercel).
- Do not add automated tests unless asked.
- New features: describe them and get the owner's OK before building. Bug fixes can go straight in.
- Be very conservative with AI credit (the owner asked): by default ("ask") only photos/PDFs go to the AI automatically; texts/emails only when the owner taps "Ask the AI". Free checks first (patterns, links, phones, email sender); the paid AI always under the daily limit (default 5) (`AI_DAILY_LIMIT`, `server/store.ts`). The same message is never paid for twice (result cache, 7 days by default). The model, daily limit (or unlimited), effort, mode and the other options live in server Settings (`AppSettings`, `server/store.ts` → `getSettings`); `AI_MODEL`/`AI_DAILY_LIMIT` are only starting values and Settings win. Several pictures at once: each is its own check and uses 1 AI check.
- The app only looks links up; it never opens or visits them. The one exception (owner's OK): 🌐 Website SEO reads the address typed into it, server-side, as text (`server/seo.ts`: http(s) only, public addresses only, re-checked on each redirect, 3 MB / 12 s). Message contents are not kept after a check (only the result: 7 days for the answer cache, and in the shared History until deleted, with its short preview), unless the owner saves it with "Keep the original".
- Never let the AI turn a strong free warning into "Looks safe" (`server/merge.ts`).
- Phone-friendly is required: check a 390px-wide layout for any UI change.
- Hosting is Vercel: `api/*.ts` are the server functions (Web `GET`/`POST` handlers), `server/` the shared code, Upstash Redis the storage. Vercel's request limit is 4.5 MB (PDFs 3 MB max) and `api/ai.ts` may run 60 s (`vercel.json`).
- ⭐ Saved keeps the key facts (`api/saved.ts` → `keyFacts`), plus the original message and picture/PDF only when "Keep the original" is ticked (owner's request); files are in Redis `sc:file:<id>`, viewable/downloadable/deletable, and removed by the automatic clean-up (Settings).
- Local: `npm run dev` also serves `api/*.ts` (plugin in `vite.config.ts`, keys from `.env.local`); without Upstash keys it uses `server/localStore.ts` (`.local/store.json`). Keep `api/` handlers runnable both ways.
- Server imports must end in `.js` (`../server/guard.js`): Vercel runs `api/` as plain Node ESM without bundling, and Node needs the extension.
- ☀️/🌙 Light and dark (owner's choice: a switch only, no auto): every colour is a CSS variable (`:root, .light` / `.dark` in `src/index.css`, read by `tailwind.config.js`), so use the palette classes, not hard-coded colours; `DevicePrefs.theme` (`src/lib/history.ts`), applied before first paint by the script in `index.html`. Check new UI in both.
- When an AI fails, hits its limit or isn't set up, the other models are offered right there (`ModelMenu`, drawn in a portal over the page): results carry `aiTried`/`tried` (marked "just failed"), and `need` greys out models that can't read pictures/PDFs. Several failed pictures can go to another model with one button (Check).
- Look: "Light futuristic" (misty grid background, frosted-glass cards with a thin cyan→violet top edge, score rings, mono HUD labels, muted palette in `tailwind.config.js`, motion behind `prefers-reduced-motion`). Tabs with icons at the top. Pages use `Shell` (`src/components/ui.tsx`): centred main column with side panels on big screens; anything important must also be in the centre (phones only show the centre). Keep it clearly different from the owner's other (dark) apps, and no scary examples in the Guide.
- Saved names: "N-What it is" (`api/saved.ts`: a counter that only goes up + the AI's `title`, else who it pretends to be, etc.); renamable; downloads use the name.
- QR codes are read on the device (`src/lib/qr.ts`: BarcodeDetector, else jsQR); kind `qr` sends only the decoded text (free, no AI, the photo isn't sent). Any picture with a QR code gets its link added to the text that is checked.
- 📅 Bills: the AI fills `bill` (company, amount, due date, last 4) for safe bills only; `api/ai.ts` → `recordBill` (`sc:bills`, key = company + due date, so one bill counts once) and `billCompare` with the same company's previous bill. Shown in ⭐ Saved → 📅 Bills. No extra AI call. Setting `bills.track`.
- ✅ Trusted / 🚫 Blocked (`sc:lists`, `server/lists.ts`): applied to every result on the way out (`out()` in `api/check.ts`), never stored into results, so changes count at once. Blocked = hard sign (≥ 92). Trusted only lowers by 20 and never below "suspicious" when there is a strong free warning.
- 🎙️ Voicemail (kind `voicemail`): recordings are shrunk on the device to a mono WAV (16 kHz up to 90 s, else 8 kHz, max 3 min: `readAudio` in `src/lib/api.ts`) to stay under Vercel's 4.5 MB. Gemini listens; any other model gets the words from Groq's free Whisper (`transcribe` in `server/openai.ts`), else Gemini if set up (`askAi` in `server/ai.ts`). Free checks run on what was said.
- iPhone: no native app (needs a Mac + paid Apple account); the website is added to the Home Screen from Safari (apple-mobile-web-app tags in `index.html`).
- 📂 Fold (`Fold` in `src/components/ui.tsx`, `openFold` event): every Settings section starts closed (owner's choice); result details (Why, Found in the message) start closed, What to do open.
- 🗑 Delete everywhere: `deleteChecks`/`deleteAllChecks` (`src/lib/batch.ts`) remove a check from History, the originals on the device, the Check screen and the server (`DELETE /api/check?ids=`); videos `DELETE /api/video?id=`, companies `DELETE /api/company?name=`. ⭐ Saved copies stay.
- 🔄 Same on every device: History (`sc:history`, last 100, written by `saveResult`), video checks (`sc:videos`, 50) and recent companies (`sc:companies`, 20) are server lists (`syncedPut/List/Del` in `server/store.ts`), read with GET `/api/check`, `/api/video`, `/api/company` (no id) and kept on the device only as a cache (`syncHistory` in `src/lib/batch.ts`, on start and on return to the app). Each device uploads its old local lists once (PUT, flags `sc.historyShared` etc.). Per device only: theme, text size, access code, originals for Re-check.
- 📄 Docs tab (`api/doc.ts`, `src/pages/Docs.tsx`, `src/lib/docs.ts`): summary, key points, red flags, actions, dates; or compare two versions. Words are taken out on the device (pdf.js lazy-loaded, its worker renamed .js in `vite.config.ts`; .docx/.odt/.pptx via a tiny unzip with DecompressionStream; text files); scanned PDFs go as the PDF (Claude/Gemini, 3 MB), photos of pages as pictures (≤6). id = hash of the content, so the same document is free; only the analysis is kept (`sc:doc:<id>` 90 days, `sc:docs` shared list). maxDuration 300.
- 🌐 Website SEO (a mode of 📄 Docs; shares `api/doc.ts` because the Vercel plan allows 12 functions): free checks in `server/seo.ts` (meta tags, headings, words, images, links, https, viewport, robots.txt, sitemap, speed → issues + technical score), then 1 AI check with web search (content quality, keywords, competitors typed or found, gaps, top fixes). If the AI part fails the free part is still kept. PDF report made on the device (`src/lib/seoReport.ts`, jsPDF lazy-loaded). Each run kept separately in `sc:docs`.
- 📰 Scams going around now (`ScamNewsFold` on Check, `POST /api/company {news: true}`, `sc:news`): made only when tapped (1 AI check, web search), shared, offered again after 7 days.
- 🔎 History search and filters (word/company/website/number, verdict, kind): on the device, over the synced list.
- ⚡ Quick look-up (`api/lookup.ts`): just a link, number or email address; free checks only, never the AI.
- Two AIs in one list (Settings → AI → AI model): Claude (paid, default) or Gemini (free, `server/gemini.ts`, plain REST, `GEMINI_API_KEY`), each with its own daily limit (`sc:ai:` / `sc:gem:`). `pickAi()` in `server/ai.ts`: the picked model checks everything (the owner removed the "bills to Claude" switch; `privateToClaude` is unused). Gemini Pro falls back to Flash when its free allowance runs out. Same prompt and answer schema for both; results carry `aiBy`.
- Running checks live in `src/lib/batch.ts` (outside the Check screen, so switching tabs keeps them); all items are sent at once and `api/ai.ts` finishes each with `waitUntil` even if the app closes; History polls `pending` ones. ↻ Re-check (`fresh: true`) asks the AI picked now, using the original kept on the device (`src/lib/inputs.ts`, IndexedDB, pruned with History). Remembered answers are marked `remembered`.
- AIs: registry `PROVIDERS` in `src/lib/types.ts` (Claude, Gemini, Groq, OpenRouter; Mistral was removed: not free; models, picture/PDF support, key env). Groq/OpenRouter share `server/openai.ts` (OpenAI-style API; no PDFs → Gemini/Claude; no-picture model → that AI's picture model). Each AI has its own daily limit (`freeDailyLimit` for the two).
- Everything follows the model picked in Settings (Check, Video, Look up). When it's over today's limit or fails, the owner picks another model just for that once (`ModelMenu`, `src/components/ModelMenu.tsx`; requests carry `model: {provider, id}`). Video and Look up go through `server/search.ts` → `askWithSearch` (Gemini: Google Search; Claude: Anthropic web search, about 1 cent a search; Groq: `groq/compound`, text only; OpenRouter can't search, so it can't do company look-ups).
- 🎬 Video tab (`api/video.ts`): with Gemini, uploads go straight from the device to Google (resumable upload opened by the server; key stays on the server) and YouTube links are watched whole. Other models get 6 pictures taken from the video on the device (`videoFrames`, no sound); links without Gemini use the title + thumbnail (oEmbed). Sources shown; results kept 30 days (`sc:video:<id>`) and polled, so leaving the tab is fine. maxDuration 300.
- 🏢 Look up tab (`api/company.ts`): company contact details only from a live web search (never from memory), website/phones re-checked by the free checks, cached 7 days (not when another model is picked). The ⚡ quick look-up lives here too. Check has no typing (owner's choice): Screenshot, Bill, Email (.eml), QR code; shared texts show as a card.
